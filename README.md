## 📖 Overview

**FOOD HAS FEELINGS** is a browser-based 3D indie diorama set in a warm, sunlit kitchen. 

The player is not just an observer, but the gentle caretaker of this tiny world. Objects have personalities, express their emotions visually, and form friendships when brought together.

### ✨ Key Features

- **Cozy Low-Poly Diorama**: Handcrafted pastel-and-wood kitchen bathed in morning sunlight, floating dust motes, and soft shadows.
- **Living Characters**:
  - 🍓 **Berry**: A shy, curious strawberry hiding on the pantry shelf who loves sunlight.
  - ☕ **Mug**: Warm, caring, and worries about cooling down.
  - 🍞 **Toaster**: Playful, lively, and longs for golden toast.
  - 📻 **Radio**: Dreamy and nostalgic, broadcasting cozy melodies.
  - 🍽️ **Plate**: Faithful, welcoming, ready to hold today's breakfast.
  - 🫖 **Kettle**: Watchful and gentle, keeping today's warmth safe.
- **The Kitchen Awakening**: Secret events unfold as you inspect the kitchen, coaxing Berry out into the light.
- **Toy-Like Snap & Placement System**: Move little friends between countertops, the breakfast table, the cutting board, and the sunny window sill.
- **Little Kitchen Stories Engine**: Characters react to one another and their surroundings. Pairing them unlocks emotional moments:
  - *First Morning Together* (Berry + Mug on the Window Sill)
  - *Breakfast Promise* (Toaster + Plate)
  - *Freshly Steeped* (Kettle + Mug)
  - *A Place at the Table* (Berry + Plate)
  - *Morning Symphony* (Berry + Radio)
  - *A Glimpse of the World* (Berry admiring the window view)
- **Collectible Postcard Memory Album**: Zero game numbers or grindy points—memories are preserved as vintage postcards with stamps and gentle story notes.
- **Subtle Player Presence**: Berry's gaze smoothly follows your cursor, and friends whisper quiet words of comfort when held gently.
- **Procedural Web Audio Engine**: Zero external audio files—100% synthesized cozy radio static, spring pops, gentle drops, and harmonic chimes.

## 🛠️ Tech Stack

- **Framework**: React 19 + TypeScript
- **3D Graphics**: Three.js, React Three Fiber (`@react-three/fiber`), React Three Drei (`@react-three/drei`)
- **Styling**: Vanilla CSS custom design system (warm watercolor aesthetic)
- **Audio**: Web Audio API (procedural synthesis)
- **Build Tool**: Vite 8

## 🚀 Getting Started

### Prerequisites

- Node.js (v18+ recommended)
- npm / pnpm / yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/Hoang20444/Food-has-feeling.git

# Navigate into project directory
cd Food-has-feeling

# Install dependencies
npm install

# Start local development server
npm run dev
```

Open your browser at `http://localhost:5173` to explore the kitchen.

### Building for Production

```bash
npm run build
```
